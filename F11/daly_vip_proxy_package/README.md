# Daly Alpha VIP Proxy

هذه النسخة تجعل **مفتاح Gemini مخفيًا على الخادم** بدل وضعه داخل الواجهة، وتحوّل قسم VIP إلى **أكواد تفعيل قصيرة** تعطيها لأصدقائك.

## ما الذي تغيّر
- `public/index.html` صار يستخدم **Activation Code** بدل إدخال Google API Key.
- طلبات Gemini تمر عبر `server.js`، لذلك **المفتاح الحقيقي لا يصل للمتصفح**.
- يمكنك إنشاء أكواد قصيرة من سطر الأوامر مثل `DLYA-7H3K-M9Q2`.
- كل كود له:
  - عدد أجهزة مسموح
  - مدة صلاحية اختيارية
  - جلسة VIP منفصلة لكل جهاز
  - إمكانية الإلغاء لاحقًا

## 1) تجهيز الملفات
ضع ملفات مشروعك الثابتة داخل مجلد `public/` مثل:
- `index.html` (موجود هنا بالفعل)
- `camp.png`
- `sniper.png`
- `fighter.png`
- `cavalry.png`
- `manifest.json`
- `sw.js`

إذا كانت هذه الملفات عندك أصلًا، فقط انسخها إلى `public/` بجانب `index.html`.

## 2) تثبيت الحزم
```bash
npm install
```

## 3) إعداد مفتاح Gemini على الخادم
انسخ الملف المثال:
```bash
cp .env.example .env
```
ثم ضع مفتاحك الحقيقي داخل:
```env
GEMINI_API_KEY=YOUR_REAL_KEY
```

## 4) إنشاء كود VIP قصير
مثال لكود جهاز واحد لمدة 90 يوم:
```bash
npm run create-code -- --label "Ahmad" --uses 1 --days 90
```

مثال لكود يسمح لجهازين بدون انتهاء:
```bash
npm run create-code -- --label "Friends" --uses 2 --days 0
```

ستحصل على JSON فيه الكود الصريح. انسخه وأرسله لصديقك.

## 5) عرض الأكواد الحالية
```bash
npm run list-codes
```

## 6) إلغاء كود
أولًا اعرض القائمة وخذ `id` المطلوب، ثم:
```bash
npm run revoke-code -- CODE_ID_HERE
```

## 7) تشغيل المشروع
```bash
npm start
```
ثم افتح:
```text
http://localhost:3000
```

## كيف يعمل التفعيل
1. صديقك يفتح الواجهة.
2. يضغط على قسم VIP.
3. يدخل الكود القصير.
4. الخادم يستبدل الكود بجلسة VIP مشفرة.
5. الصور تظل تُحلَّل من الواجهة، لكن طلب Gemini يمر عبر الخادم فقط.

## ملاحظات مهمة
- هذه النسخة **أفضل بكثير** من وضع مفتاح Google داخل HTML أو JavaScript.
- ما يزال من الأفضل استضافة الخادم بنفسك أو على خدمة تثق بها.
- إذا كان لديك **IP ثابت** للخادم، قيّد مفتاح Google على هذا الـ IP من Google Cloud.
- إذا كنت تريد لوحة إدارة رسومية للأكواد بدل أوامر `npm`, يمكن إضافتها لاحقًا.
